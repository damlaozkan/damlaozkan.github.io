# app-insights Privacy Policy

_Last updated: October 24, 2026_

**app-insights** is a private reporting tool used only by its developer (Zeytin Ağacı) to prepare weekly reports about the developer's own mobile apps. It is not offered to the public.

## What data it accesses

With the developer's own authorization, app-insights reads, **read-only**:

- AdMob reports for the developer's own AdMob account (estimated earnings, impressions, ad requests, match rate, show rate, eCPM), through the AdMob API with the `admob.readonly` scope.
- Sales, download and review reports for the developer's own apps from App Store Connect.
- Public App Store ratings.

It does not access any end user's personal data, and it never changes anything in these accounts.

## How the data is used and stored

The data is used only to create the weekly report. Reports are stored in the developer's private GitHub repository. Access credentials are kept as encrypted GitHub Actions secrets and are never published.

## Sharing

The data is not sold and is not shared with anyone.

## Google API Services User Data Policy

app-insights' use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
